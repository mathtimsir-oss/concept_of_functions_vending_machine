Key idea: If the same input could give two different snacks, the machine would be broken… and it would no longer be a function!

Try different codes. Watch how each input always produces the same unique output.

💡 Teacher tip: Ask “What if I press A1 twice — do I get the same snack?” Then link it to “for each value of x there is only one corresponding value of y”.
